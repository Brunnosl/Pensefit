PENSEFIT 2.0

Login, cadastro e registros sincronizados com o Supabase.

COMO ABRIR
Na pasta PENSEFIT, execute:
  python -m http.server 3000 --directory dist
Depois acesse http://localhost:3000/
Ou abra INICIAR-PENSEFIT.bat no Windows.

Leia README.md para detalhes do projeto e das verificações.

PENDÊNCIA PARA E-MAILS
Configure um provedor SMTP no Supabase para confirmar cadastros e recuperar senhas de usuários em geral. As instruções e os links estão em README.md.
Confira também as URLs de retorno antes de testar links enviados por e-mail.
